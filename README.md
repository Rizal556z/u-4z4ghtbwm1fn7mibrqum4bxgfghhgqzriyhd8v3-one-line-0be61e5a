# One Line, One Laugh

One funny line of text, written by a pure-stdlib Python program for the make.fun bounty **One Line, One Laugh**.

> My doctor told me to cut back on stress, so I stopped reading my own group chats.

Run `python3 main.py` — it writes the line (one line, 81 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–140 characters, single line, no trailing newline).
